# Lucky Maths

**Lucky Maths** is a 2D arcade puzzle game developed in Unity 6.3 using C#. The game challenges players to solve mathematical operations by selecting the correct numbers from a set of six options before the countdown timer runs out.

Players must think quickly, identify the three correct numbers, and build combo streaks to maximize their score.

---

## Technical Highlights

* **Procedural Operation Generation:** Implements a modular generation system that creates mathematical expressions using five different operation types: multiplication, addition, subtraction, and division combinations.
* **Number Selection & Validation:** Features a selection system that allows players to choose three numbers in the correct order, validating their answer against the generated expression.
* **Combo-Based Scoring:** Implements a multiplier system that rewards consecutive correct answers on the first attempt, encouraging accuracy and consistency.
* **Game State Management:** Uses a centralized game manager to control gameplay states, manage the game-over sequence, and handle restarts.
* **Visual Feedback:** Provides immediate visual feedback through color changes when players submit correct or incorrect answers.
* **Time-Based Gameplay:** Includes a countdown timer that determines the duration of each session.
